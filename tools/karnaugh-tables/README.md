# Karnaugh Tables

Karnaugh-map exercise tool that creates random filled tables so students can practice finding legal groupings.

## Run

Open `index.html` in a browser, or run:

```bash
./launch.sh
```

From the repository root, the tool is also available through the Bitland Empire hub:

```bash
npm run start:hub
npm run start:hub:web
```

## Electron development

From the repository root:

```bash
npm run start:karnaugh
```
